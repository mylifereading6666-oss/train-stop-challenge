# TRAIN STOP CHALLENGE

停止目標を短時間で観察して記憶し、目標が見えなくなったあと、制限時間内にブレーキ操作で列車を停車させる2Dブラウザゲームです。

## 公開サイト
https://mylifereading6666-oss.github.io/train-stop-challenge/

## ゲームの流れ
1. 「運転を開始する」を押すと、駅・初速・停止目標がランダムに決まります。
2. **3秒間の観察フェーズ**で、ホーム上の停止目標の位置を覚えます。
3. 目標マーカーと目標距離が隠れ、列車が走り始めます。
4. **7秒間の調整フェーズ**で、弱・中・強ブレーキを押している間だけ減速させます。惰行ボタンでブレーキを解除できます。
5. 7秒が経過すると自動制動に切り替わり、列車が停止します。
6. 停車後に目標マーカーが再表示され、誤差・評価・スコアを確認できます。
7. 「もう一度」で新しいランダム条件に挑戦できます。

固定ステージ制ではありません。毎回、駅・初速・停止目標が変わるエンドレスチャレンジです。

## 主な機能
- スマートフォン・タブレット・PC対応
- タッチ／マウス操作
- 3秒の観察と7秒の時間制限付きブレーキ操作
- 目標を隠した状態での停車チャレンジと停車後の答え合わせ
- ランダム条件、停車位置・誤差・スコア判定
- 30種類の実績、解除日時、進行記録
- IndexedDBによる端末内自動保存
- 引き継ぎコードの発行・コピー・復元
- JSONバックアップファイルの書き出し・読み込み
- 引き継ぎコードはAES-256-GCMで暗号化・認証
- Service Workerによるオフラインキャッシュ
- BGM・効果音の個別設定
- サーバー、ログイン、外部API、外部データベース不使用

## 保存・引き継ぎの注意
セーブデータはブラウザのIndexedDBに保存されます。端末・ブラウザ・プロファイルごとに別データです。サイトデータ削除などで消える可能性があるため、定期的にバックアップしてください。

引き継ぎコードは復元鍵を含む秘密情報です。第三者に共有しないでください。コードを持つ人はデータを復元できます。コードの暗号化は改ざん検知とデータ保護を提供しますが、コードを入手した人からデータを秘密にするものではありません。

JSONバックアップファイルは読み込み可能なセーブデータを含みます。ファイル自体にパスワード暗号化はかけていないため、第三者に見られない場所へ保管してください。

## ローカルでの起動
HTTPS配信、または localhost で開いてください。IndexedDB・Web Crypto API・Service Worker の利用にはブラウザ側の制約があります。単純にHTMLをファイルとして開く場合、引き継ぎやオフライン機能の一部が使えないことがあります。
